# MetaRush

MetaRush es una aplicación de escritorio para Windows enfocada en la gestión y seguimiento de metas personales.

Fue desarrollada con C#, .NET, WPF y XAML.

---

## 📌 Estado del proyecto

✅ Aplicación terminada  
✅ Publicada en Microsoft Store  
✅ Disponible para Windows
---

## 🚀 Funcionalidades

- Creación de metas personales.
- Administración de metas existentes.
- Seguimiento del progreso.
- Interfaz gráfica desarrollada con WPF.
- Persistencia local de información.
- Aplicación publicada oficialmente en Microsoft Store.

---

## 🛠 Tecnologías utilizadas

- C#
- .NET
- WPF
- XAML
- Visual Studio
- Microsoft Store

---

## 🖥️ Plataforma

MetaRush fue desarrollada como aplicación de escritorio para Windows.
